# Security

Included: Helmet, CORS configuration, JSON size limit, bearer authentication, JWT expiration, validation, authorization primitive, generic internal errors, request IDs and environment-based secrets.

Production hardening: OIDC/OAuth identity provider, password hashing if credentials are owned by the service, asymmetric JWT keys and rotation, refresh-token lifecycle, rate limiting, strict CORS, gateway/WAF, secret manager, least-privilege database credentials, encryption, SCA/SAST/DAST, container scanning and privileged-operation audit logging.
